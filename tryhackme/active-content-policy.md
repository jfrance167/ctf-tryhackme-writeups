# Public Writeup Policy for Active Training Content

## Why this repository does not publish active-room solutions

TryHackMe's Acceptable Use Policy prohibits sharing flags, answers, solutions, exploit code written for a specific room, and step-by-step walkthroughs for active content. Public writeups are reserved for content that TryHackMe has explicitly designated as retired.

Accordingly, this repository does not publish room-specific answers, flags, target details, screenshots, or walkthroughs unless retirement status has been confirmed first.

## Safe portfolio evidence

For active training, keep detailed notes privately. Public portfolio material should instead show original skills without reproducing protected content:

- a sanitized detection rule created from synthetic events;
- an original packet capture generated in a personal lab;
- a methodology diagram explaining scope, evidence handling, and mitigation;
- a short reflection on a concept without naming room tasks, answers, or solution paths.

## Before publishing a retired-room writeup

1. Confirm that TryHackMe marks the content as retired.
2. Re-read the current writeup guidance and Acceptable Use Policy.
3. Exclude flags, credentials, tokens, personal data, and any live target details.
4. Add only original screenshots that are redacted and necessary to explain the finding.
5. Document mitigations and defensive validation, not just exploitation steps.
